# Практична робота №2 з Python

**Виконав:** Качоровський ДаніІл (КІб-1-24-4.0д)

## Опис

Цей репозиторій містить виконання завдань з практичної роботи №2 на тему "Розробка та застосування ітераторів та генераторів у Python для ефективної обробки даних":

- `task1.1.py` — Реалізація власного класу-ітератора `CyclicRange` з підтримкою циклічної генерації чисел із заданим кроком та кількістю повторень.
- `task1.2.py` — Ітерабельний контейнер `StudentGroup` з окремим класом-ітератором `StudentGroupIterator` для незалежного багаторазового обходу.
- `task2.1.py` — Функції-генератори для числових послідовностей: арифметична прогресія, геометрична прогресія, числа Фібоначчі, послідовність Коллатца та рекурсивне розгортання вкладених списків через `yield from`.
- `task2.2.py` — Конвеєр із п'яти функцій-генераторів для обробки даних про оцінки студентів без створення проміжних списків у пам'яті.
- `task3.1.py` — Порівняння `list comprehension` та `generator expression` за використанням пам'яті та продуктивністю з використанням `sys.getsizeof()` та `timeit`.
